# 🧵 GTracker | Smart Garments Order & Production Tracking System

## 👕 Project Theme
**GTracker** is a modern, web-based garments **order and production tracking system** designed to digitize factory workflows.  
It connects **buyers, factories, and production teams** in one platform, ensuring transparency, accuracy, and real-time progress tracking throughout the garments manufacturing lifecycle.

---

## 🎯 Purpose
The main purpose of **GTracker** is to eliminate manual tracking, paperwork, and communication gaps in garments production.  
The system enables businesses to **place orders, track production stages, manage inventory, and analyze performance**, ensuring timely delivery and improved operational efficiency.

## ✨ Key Features
- 🏠 **Home Page** – Modern landing page with smooth animations and clear call-to-action  
- 📦 **All Products Page** – Displays all garments in a 3-column card grid layout  
- 🧾 **Product Details Page** – Detailed view with category, price, stock, and description  
- 🛒 **Order Now System** – Simple and secure order placement with quantity validation  
- 📊 **Production Tracking** – Track stages like cutting, sewing, finishing, and delivery  
- 📈 **Dashboard & Analytics** – Visual insights into orders, production status, and performance  
- 🧑‍💼 **User Management** – Role-based access for Admin, Staff, and Buyers  
- 📢 **Notices & Updates** – Factory-wide announcements and updates  
- 📞 **Contact Page** – Easy-to-use contact form and business information  
- 🌍 **About Section** – Vision, mission, and system overview  
- 📱 **Responsive Design** – Optimized for mobile, tablet, and desktop devices
